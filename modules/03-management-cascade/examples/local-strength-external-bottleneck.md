# Synthetic Example: Local Strength, External Bottleneck

This example is invented to demonstrate the method.

## Situation

A manager gives clear feedback, protects focus, attributes credit accurately,
and invests in each team member. The team trusts the manager.

However, the manager receives strategic changes late and rarely brings team
evidence into cross-organization decisions.

## Pathway map

```text
Channel: context
Needed movement: customer priority changes into planning
Current route: senior meeting -> manager -> team
Evidence that it arrived: team repeatedly replans after work begins
Failure mode: delay
Fallback: shared decision log and project-lead attendance when relevant

Channel: evidence
Needed movement: operational learning into roadmap decisions
Current route: team -> manager -> senior review
Evidence that it arrived: no reference to the learning in the decision
Failure mode: absence
Fallback: written evidence brief with named contributors
```

## Interpretation

Strong local management is real evidence for M. It does not prove that S or E
pathways are strong.

The remedy is not generic networking. It is a bounded redesign of the missing
context and evidence routes.
