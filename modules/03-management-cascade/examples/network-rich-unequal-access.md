# Synthetic Example: Network-Rich, Unequal Access

This example is invented to demonstrate the method.

## Situation

A manager has strong relationships across the organization and can quickly
secure introductions, resources, and presentation opportunities.

Over six months, nearly every visible assignment goes to the same two people.
Other qualified contributors remain represented secondhand.

## Diagnosis

```text
Relationships: strong route exists
Resources: route frequently succeeds
Opportunity: concentrated
Evidence: accurate for selected people, absent for others
Dependency: manager remains the broker for all external access
```

## Response

The manager:

- publishes relevant selection criteria;
- reviews prior opportunity distribution;
- checks interest and workload;
- creates direct working relationships for additional qualified people;
- preserves support for the original two rather than treating fairness as
  automatic rotation.

A large network is not an equitable cascade unless access travels through it
fairly.
