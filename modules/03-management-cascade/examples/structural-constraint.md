# Synthetic Example: A Structural Constraint

This example is invented to demonstrate the method.

## Situation

A manager accurately represents a team need, provides evidence, and proposes
several options. Senior leadership declines additional staffing because the
organization is reducing cost.

## Weak interpretations

```text
The manager lacks influence.
The team is not valued.
The individuals should work harder to become visible.
```

None follows automatically from the decision.

## Pathway map

```text
Channel: resources
Needed movement: additional operational capacity
Current route: team evidence -> manager proposal -> portfolio decision
Evidence that it arrived: decision record addresses the request and evidence
Failure mode: route worked; resource remains unavailable
Fallback: reduce scope, change service level, or stop lower-priority work
```

## Interpretation

A functioning cascade cannot guarantee a favorable decision.

The manager remains responsible for making the constraint and tradeoff clear.
The organization remains responsible for the consequence of the resource
decision.
