# Synthetic Example: An Inherited Struggling System

This example is invented to demonstrate the method.

## Situation

A new manager inherits:

- several unfilled roles;
- an unreliable service;
- conflicting commitments;
- low confidence after repeated reorganizations.

Delivery remains unstable during the first operating cycles.

## Weak interpretations

```text
The new manager has failed because the team outcome is poor.
The new manager is effective because the team likes the new approach.
```

Neither conclusion is adequately supported.

## Evidence record

```text
Management condition: commitment clarity
Observed management act: reconciled work into one ranked plan
Team or system signal: conflicting requests declined with shared rationale
Counterevidence: reliability work still lacks enough staffing
Inherited context: vacancies and unresolved operational debt
Confidence: medium
Next experiment: remove one low-priority commitment and measure interruption
```

The record preserves accountability without pretending the manager caused or
can immediately repair every inherited condition.
