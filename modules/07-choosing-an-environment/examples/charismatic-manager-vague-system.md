# Synthetic Example: Charismatic Manager, Vague System

This example is invented to demonstrate the method.

## Situation

A hiring manager is warm, inspiring, and specific about the product vision.

Questions about decision authority, workload, feedback, and opportunity receive
general answers:

```text
We move fast.
Everyone gets exposure.
Great work speaks for itself.
We figure things out together.
```

## Evidence record

```text
Manager warmth: direct observation
Product vision: specific example
Decision authority: unknown
Workload: unknown
Opportunity allocation: general statement only
Feedback practice: unknown
```

## Response

The candidate asks for:

- one recent delegated decision;
- one example of a priority change;
- one peer conversation;
- written confirmation of on-call and travel expectations.

Charisma remains a positive signal. It is not allowed to fill unrelated
evidence gaps.
