# Synthetic Example: Manager Departure with Strong Prior Advocacy

This example is invented to demonstrate the method.

## Before

```text
M: 8-9
Evidence: manager named the person's contribution, opened a cross-team
opportunity, and backed the work during challenge
S: 6-7
E: unknown
```

The manager leaves.

## Transition record

```text
Prior M: retired as a current route
Prior manager evidence: preserved in dated history
Work evidence: carried to the incoming manager
Current M: unknown
Current S: continuing; same next-level leader retains authority
Current E: unknown
```

The outgoing manager documents contribution, shared credit, active work, and
one development commitment. The next-level leader names interim authority.

The incoming manager reviews the record, hears the person's account, and
establishes current expectations. They do not inherit an M score or disregard
the prior evidence.
