# Synthetic Example: Returning Employee with Outdated Relationships

This example is invented to demonstrate the method.

## Situation

A former employee returns after several years. A senior leader who previously
supported them encouraged the conversation, but the team, role, and manager
have changed.

## Diligence

```text
Prior work evidence: portable with context
Prior senior advocacy: historical
Current manager: new relationship
Current next-level route: different
Current senior sponsor route: unknown
Organizational knowledge: useful but partly stale
```

The returning employee receives ordinary onboarding and verifies which
conditions that led to the earlier departure have changed.

The senior introduction provides access. It does not create an arrival E score,
guaranteed premium, or shortened promotion path.
