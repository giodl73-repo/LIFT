# Synthetic Example: Return from Leave Without an Evidence Penalty

This example is invented to demonstrate the method.

## Situation

A person returns from approved leave. During the absence, the team adopted a
new planning process and changed two priorities.

The reason for leave is private.

## Transition record

```text
Pre-leave profile: preserved with date
Evidence opportunities during leave: paused
Role: continuing
Manager: continuing
Current priorities: changed
Access and training: required before normal execution
Evaluation: based on work performed, not time absent
```

The manager provides reboarding, restores access, explains decisions made
during the absence, and confirms current expectations.

No score is reduced because advocacy behavior was not observable during leave.
The person is not required to disclose private details to regain standing.
