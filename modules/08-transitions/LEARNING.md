# Module 08 Learning

## Source lesson

The private source correctly recognized that manager departures, transfers,
external moves, and returns disrupt relationships differently. It also
recognized the value of handoffs, explicit expectations, and organizational
context.

It turned those observations into fixed arrival profiles, score sums, universal
reset values, 90-day locks, recovery timelines, prestige adjustments, and
generated promotion forecasts.

## Changes in the public rewrite

- score reset became evidence remapping;
- a dated historical profile replaced overwritten history;
- continuing, carried, paused, stale, retired, and unknown replaced numeric
  transition defaults;
- work evidence was separated from current advocacy;
- M/S/E attached to current authority rather than permanent people;
- Snapshot-Map-Carry-Contract-Observe-Reassess replaced transition clocks;
- a bounded handoff replaced narrative control;
- a commitment ledger replaced silent promise loss or automatic inheritance;
- organizations gained explicit continuity responsibilities;
- manager changes no longer force people to compete for early impressions;
- internal transfer gained reboarding and authority remapping;
- reorganizations gained decision and commitment ownership;
- leave gained privacy, paused evidence, and no adverse commitment inference;
- returning employees gained current diligence rather than a presumed premium;
- following a manager gained a dependency and authority check;
- all score sums, arrival profiles, level premiums, success rates, fixed
  windows, and promotion forecasts were removed.

## Open learning questions

- Can people distinguish `carried` from `continuing` evidence?
- Is `paused` safe and useful during leave?
- How much handoff detail preserves context without creating surveillance?
- Who should own commitment disposition during a reorganization?
- Can small organizations run the loop without excessive ceremony?
- How should serious contested evidence be preserved fairly?
- Which transition triggers justify reassessment?
- Does the authority map remain understandable in matrix organizations?
