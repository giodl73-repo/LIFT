# Synthetic Example: Coerced Team Profile Collection

This example is invented to demonstrate the method.

## Situation

A manager asks every report to submit an M/S/E profile to a shared dashboard.
The manager says participation is optional but will use the exercise to assess
"self-awareness."

## Ethical-use gate

```text
Purpose: linked to manager evaluation
Voluntary: no; refusal can affect reputation
Audience: manager and team
Employment-decision risk: material
Retention: undefined
Correction route: manager controls it
Disposition: do not collect
```

The manager may review their own advocacy practices or invite a private,
non-evaluative discussion with a genuine alternative.

Consent language does not cure the power imbalance.
