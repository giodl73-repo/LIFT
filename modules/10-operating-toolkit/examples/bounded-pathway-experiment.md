# Synthetic Example: One Bounded Pathway Experiment

This example is invented to demonstrate the toolkit.

## Record

```text
Purpose: reduce delayed context for operations
Dimension or channel: context
Current route: senior review -> project lead -> weekly meeting
Observed failure: operations learns changed constraints after implementation
begins

Bounded action: publish one decision note within one working day and include
the operations owner
Owner: project lead
Support required: decision-note template and distribution access
Expected evidence: operations can explain the changed constraint before work
starts
Stop condition: note exposes confidential customer information
Review trigger: next changed-scope decision
```

The experiment tests a pathway. It does not target a score increase.
