# Contributing

Contributions should make LIFT more honest, useful, safe, and portable.

Before proposing a claim:

1. identify its evidence class from `EVIDENCE_POLICY.md`;
2. remove private workplace provenance;
3. state uncertainty and counterexamples;
4. explain how a practitioner could observe or test it;
5. run the relevant roles from `.roles/ROLE.md`.

Do not submit personal promotion packets, private assessments, employer policy,
or unsupported claims about demographic or organizational groups.
