# When Your Manager Changes

Use this guide when a manager leaves, reporting lines change, or an interim
manager takes over.

A transition changes authority and evidence pathways. It does not reset a
person to a universal score.

## Preserve the old snapshot

Before changing the current record, preserve:

- the prior role and context;
- the evidence window;
- M/S/E evidence and uncertainty;
- open commitments;
- sources that should not be shared;
- decisions that were still unresolved.

Do not rewrite the old record as if the new manager had always been present.

## Map the change

```text
Transition:
Effective date:
Authority that moved:
Work that remained:
New decision owners:
Changed evidence pathways:
Commitments requiring disposition:
Material unknowns:
```

For each evidence item, choose:

- `continuing`;
- `carried`;
- `paused`;
- `stale`;
- `retired`;
- `unknown`.

Carried evidence can describe prior work. It does not prove that a new manager
advocates for it.

## Ask for a bounded handoff

A work-relevant handoff may include:

- current scope and decisions;
- observable contribution evidence;
- active commitments;
- access or resource constraints;
- corrections to factual errors;
- what the new manager still needs to learn.

Exclude:

- gossip;
- protected information;
- speculative personality judgments;
- private career decisions;
- confidential sources;
- an inherited score presented as fact.

Missing handoff is an organizational gap, not negative evidence about the
person.

## Establish the new operating contract

Ask:

- What decisions do you own?
- What decisions remain elsewhere?
- How should concerns be raised?
- How will contribution be attributed?
- Which commitments continue?
- What evidence would help you understand the work?
- What event should trigger a reassessment?

The goal is not to secure a fast favorable judgment. It is to make authority,
evidence, and commitments inspectable.

## If the former manager invites you to follow

Treat this as an environment and transition decision, not inherited
sponsorship.

Inspect:

- role reality;
- new manager authority;
- team conditions;
- evidence pathways;
- written terms;
- dependencies on one relationship;
- what becomes `unknown` in the new context.

Do not assume advocacy transfers across organizations.

## Common traps

- assigning a universal reset score;
- treating the first interaction as a durable judgment;
- oversharing private records to establish credibility;
- asking the former manager to write a personality narrative;
- assuming all prior commitments continue;
- following a manager solely because the relationship was strong;
- treating missing evidence as negative evidence.

Use the [transition record](../toolkit/templates/transition.md).

## What this guide cannot tell you

- how quickly a new relationship will form;
- whether staying or following is correct;
- what the new manager privately believes;
- whether prior advocacy will continue;
- whether a transition will improve an employment outcome.
