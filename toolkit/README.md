# LIFT Operating Toolkit

These are blank Markdown templates for private reflection and disclosed,
permitted conversations.

## Start with one record

| Need | Template |
|---|---|
| inspect current M/S/E evidence | [Private profile](templates/private-profile.md) |
| test one advocacy or pathway change | [Pathway experiment](templates/pathway-experiment.md) |
| interpret a team or management signal | [Team signal](templates/team-signal.md) |
| evaluate a prospective environment | [Environment diligence](templates/environment-diligence.md) |
| preserve evidence through change | [Transition](templates/transition.md) |
| prepare a minimal disclosed discussion | [Shared conversation](templates/shared-conversation.md) |
| check whether sharing or reuse is safe | [Ethical-use check](templates/ethical-use-check.md) |

Do not complete every template. Use the smallest record that answers the
current question.

## Private-first setup

1. Copy the blank template to a private storage location you control or are
   authorized to use.
2. Remove fields you do not need.
3. State the purpose and review trigger.
4. Record evidence before a score.
5. Keep protected, private, speculative, and surveilled information out.
6. Share a separate minimal conversation record rather than the private file.
7. Archive or delete the record when its purpose ends.

Do not commit filled records to this public repository or another shared source
control system.

Do not submit filled identifiable records to a public AI service.

## Not included

The toolkit has no:

- database;
- dashboard;
- score total;
- cross-person comparison;
- reminders;
- automated inference;
- HR or talent-system integration;
- hiring or promotion workflow;
- AI scoring;
- software dependency.

See [Module 10](../modules/10-operating-toolkit/README.md) for the operating
practice and [ETHICAL_USE.md](../ETHICAL_USE.md) for permitted use.
