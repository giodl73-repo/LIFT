# Independent-Review Index

No independent-human review has been admitted yet.

This directory will index sanitized reports produced under
[INDEPENDENT_REVIEW.md](../../INDEPENDENT_REVIEW.md).

## Required index fields

| Field | Purpose |
|---|---|
| date | when the attempt occurred |
| module and task | exact bounded scope |
| commit or version | artifact reviewed |
| evidence state | unreviewed, attempted, usable with findings, or independently usable |
| findings | unresolved critical, major, and minor items |
| limitations | what the attempt does not support |
| disposition | accepted, clarified, deferred, declined, or removed |
| report | link to the sanitized report |

## Admission rules

- the reviewer meets the independence boundary;
- the report identifies a public commit or version;
- no completed profile, score, or private workplace evidence is included;
- the attempted task and outcome are visible;
- safety and accessibility findings are preserved;
- maintainer disposition is recorded;
- dissent is retained when publication is safe.

An entry is evidence about one attempt. It is not a testimonial, endorsement,
certification, research result, or validation of LIFT as a whole.
